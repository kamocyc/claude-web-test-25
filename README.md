# 里山（Satoyama）

Timberborn 風のコロニーシミュレーション。ただしビーバーではなく、**日本の里山の村**を育てる。
川に堰を架けて水位を上げ、用水路で田に水を引き、日照りと大雨と火事をやり過ごしながら
村を続かせるのが目的。

TypeScript + Vite + Three.js のみで動く、ブラウザ完結のゲーム。

```bash
npm install
npm run dev      # http://localhost:5173
npm test         # シミュレーションのテスト（Vitest）
npm run build    # 型チェック + 本番ビルド
```

## このゲームの芯

**一本の水路が三つの役目を兼ねる。**

```
川 ──堰と水門で水位を上げる──┐
                              ├─ 浅く引く → 水田が湛水する → 籾 → 精米所 → 米（主食）
                              ├─ 深く掘る → 運河になる → 船着場 → 遠くの荷が一気に捌ける
                              └─ 町中を通す → 延焼を止める火除け地 ＋ 消火の水
```

どこにどう水を通すかが、そのまま町作りの主題になる。

**サンプル** ボタンを押すと、堰で水位を上げ、用水路で田に水を引き、運河と船着場で
出作りの田をつなぎ、村を堤防で囲い、火の見櫓と火消し詰所まで揃った村を読み込める。
何から手を付けるか迷ったらこれを見るとよい（今の村は捨てられるので確認が入る）。

サンプルの村には**筋書きが仕込んである**。数日の平年のあとに大雨が来て、その次に
日照りが来る。荒天が既定の長さ（12〜20 日）だと、放っておけばこの二つで村は倒れる。
水門を閉め、流された道を敷き直し、水の引いた田を開き直す——それがこのゲームの本番。

### 画面を畳む

村が大きくなると四隅がパネルで塞がって地面が見えなくなる。**どのパネルも見出しの
「−」で畳める**（「＋」で戻る）。畳んだ状態は覚えているので、読み込み直しても
そのままになる。

上部のバーだけは**速度のボタンを残して**畳む。丸ごと隠すと、畳んでいるあいだ
一時停止も速度変更もできなくなるため。

### 住民を見る

**住民**ボタンで村の一覧が開く。名前・肩書き（配属先）・いましていること・
足りていないものが一枚に並び、見出しに **「飢え 3」** のように人数が出る。
**困っている人が上に来る**ので、村が大きくなっても誰が参っているかすぐ分かる。
行を押すとその人に寄って、右のパネルに詳細（需要の残りと余命）が出る。

需要が尽きている人がいれば、一覧を開いていなくても画面上部に赤く人数が出る。
そのまま放っておくと力尽きるが、**そのときは何で死んだのか（渇き／飢え）がログに残る**。

### 水分補給と食事

住民は 1.5 日で水を、2 日で食べ物を切らす。減ってくると仕事を中断して**蔵まで
飲み食いに行く**（水も米も蔵の共有の蓄えから減る）。水を蔵へ入れるのは**踏車**だけで、
踏車は隣に水深 0.5 以上の水があり、働き手が出勤しているあいだだけ回る。

```
川・貯水池 ──踏車（働き手 1）──→ 蔵の「水」──→ 住民が飲む／精米所が使う
```

だから日照りで取水口が浅くなれば村の水は止まる。**堰で水位を保つことが、そのまま
水分補給の備えになる**。蔵の水が尽きると住民は飲みに行くことすらできなくなるので、
そのときは

* 画面上部に **「水が尽きた」** が出る
* ログに **「蔵の水が尽きた — 踏車を建て、取水口の水深を保つこと」** が一度だけ出る
* その人を選ぶと **「蔵に水が無い — 飲みに行けない」** と余命が出る

踏車が止まっている理由（`取水できる水がない` / `労働者がいない`）は、踏車を選べば分かる。

### 誰にどの仕事をさせるか

働き手は空きのある職場へ自動で配属される。順番は建物の種類ごとに決まっていて
（踏車がいちばん先、放水樋がいちばん後）、**建物を選んで「働き手の優先」を
高・並・低で変えられる**。

**「高」にすると、手が空いていなくても優先度の低い職場から人が移ってくる。**
日照りに踏車を建て増したのに誰も来ない、ということが起きないようにしてある。
逆に「低」に落とせば、その職場の人はほかへ回る。同じ段どうしでは動かないので、
人が職場のあいだを行ったり来たりすることはない。

### 人手が足りているか

画面上部に **「人手不足 3」** と、**人の来ていない持ち場の数**が出る。印に触れば
どこが足りないかが読め、**住民**の一覧を開けば職場ごとの内訳が並ぶ。
**その職場を押せばそこへ寄って詳細が開く**ので、建て過ぎた小屋を撤去するのか、
民家を建てて人を増やすのかをその場で決められる。

これは一覧の見出しにある **「無役 N」** とは別のものを数えている。

| 印 | 数えているもの | 効く手 |
| --- | --- | --- |
| 人手不足 N | 人の来ていない**持ち場** | 民家を建てて人を増やす／要らない職場を撤去する |
| 無役 N | 職に就いていない**人** | 職場を建てる（人は余っている） |

建設中の建物と、水に浸かって人を外してある職場（沈んだ小屋・水の合わない田）は
数えない。あそこに要るのは人手ではなく、普請と水だからである。
足りない職場は、その建物を選んだときにも **「働き手 0 / 2 — 人手が足りない」** と赤く出る。

### 最初の数日にやること

1. **踏車**を川岸に建てる。水は住民の生命線で、精米にも要る。
2. **民家**を建てて寝床を増やす（人口が増える条件でもある）。
3. **杣小屋 → 木挽小屋**で丸太と板材を確保する。
4. 川へ**堰**を架けて水位を上げ、**堀割**で岸から内陸へ溝を引く。
   水が溜まったところに**水田**を開き、**精米所**で籾を米にする。
   堰と土手は**掘って出た土**で築くので、掘ることと築くことは一続きの仕事になる。
5. 湛水の要らない**畑**も作っておく。ただし大雨では流されるので、
   **一段高い段丘**にも畑を持っておくと洪水のあいだの食いつなぎになる。
6. 水辺から離れた畑には**用水櫓**を建てて湿り気を届ける。
7. 水路や川を跨いで通うなら**橋**を架ける。水の中は歩みが 6 倍遅い。
8. 村が大きくなったら**火の見櫓**と**火消し詰所**を。日照りの火事は町ごと持っていく。

## 季節

平年・大雨・日照りをランダムに引く。直前と同じ季節は来ない。
次に何が来るかは決まっているが、**残り 2 日を切るまでは分からない**（前触れが出る）。
不意打ちにはせず、しかし最後まで分からない、という間合いにしてある。

| 季節 | 日数（荒天 = 並） | 起きること |
| --- | --- | --- |
| 平年 | 20〜28 | 川はいつも通り流れる。**人が増えるのはこの季節だけ** |
| 大雨 | 12〜20 | 水源が 5 倍。**氾濫原が水を被る**。畑は流され、稲は耐える。火が消える |
| 日照り | 12〜20（繰り返すほど長く、最大 28） | 水源が止まり蒸発 3 倍。貯めた水も目減りする。出火が 4 倍 |

季節の切り替わりは 8 時間かけて繋ぐ。そのあとは季節が終わるまでずっとその状態が続く。

大雨と日照りが何日続くかは画面上部の**荒天**（短 / 並 / 長）で変えられる。
素の日数を 1 / 2 / 3 倍する（平年は変わらない）。**並が既定**で、上の表はその値。
これはそのまま難易度になる。荒天のあいだ氾濫原の村はほとんど何も穫れないので、
長くするほど蔵の蓄えがものを言う。荒天のさなかに変えると残りもその場で伸び縮みする。

荒天が長いぶん、**人が増える条件も重くしてある**（蔵が 8 割埋まっていて、かつ平年）。
軽い条件で増やすと、次の大雨で口が増えたまま村ごと飢える。

雨は**すでに水のある列にだけ**降らせている。乾いた土は雨を吸い、水は低いところへ
流れて水面に集まる、という流出をそのまま模したもの。氾濫は水源の増水で起こすほうが、
川とつながった水として正しく引いていく。

### 浸水

大雨で水を被ると、深さに応じて次が起きる。守りは**土手**（水を止める）・**水門**
（雨の前に開けて水位を下げる）・**堀割**（逃がす）・**段丘に建てる**こと。
前触れが残り 2 日で出るので、備える猶予はある。

| 水深 | 起きること |
| --- | --- |
| 0.15 以上 | **歩みが遅くなる**（深いほど遅く、1.0 でおよそ 6 倍の時間） |
| 0.10 以上 | 畑の麦が育ちかけごと流される（稲は水田で耐える） |
| 0.30 以上 | 道が流される |
| 0.35 以上 | 建物が働けない（水が引けばそのまま戻る）／蔵の蓄えが日ごとに傷む |
| 0.50 以上 | 建物が日ごとに一定の確率で傷む。住民が建設要員として直しに来る |
| 1.00 以上 | もう歩けない。**橋**を架けるか回り道をする |
| 2.00 以上 | 木が根腐れで枯れる |

水に沈んだ職場と、水の合わなくなった田畑からは**働き手が離れる**。
使いものにならない職場に手が張り付いたまま村が飢える、ということが起きないようにしてある。

水を張って使うもの（水田）、地形そのもの（土手・堰・水門・堀割・道）、
もともと水に足を突っ込んで建てるもの（踏車・放水樋・船着場）は被害を受けない。
**土蔵**は高い基礎と漆喰で無事（蓄えも傷まず損壊もしない）。庄屋は損壊しない。

### 水の中を歩く

水に入ると足が進まない。くるぶし（0.15）までは変わらず、そこから深くなるほど遅くなり、
歩ける限界の 1.0 でおよそ 6 倍の時間がかかる。**経路探索の重みにも同じ値が効く**ので、
住民は深いところを突っ切らず、浅瀬や橋を選んで回り道をする。

だから水を跨ぐには**橋**を架ける。桁の上は乾いた地面と同じ速さで歩けて、水は下を
流れるので**川の流れも水位も変わらない**（土手や堰と違うのはここ）。桁の高さは
繋いだ岸から受け継ぐので、堰と同じく**岸から一マスずつ継ぎ足して**伸ばすことになる。
増水して桁を越えれば、橋の上も水の中と同じように歩きにくくなる。

### 蒸発

蒸発は水面で起きるので深さでそれほど変わらない（浅いほうが少しだけ速い）。
日照りが 10 日続けば、2 m の貯水池でも 0.5 m ほど減る。**溜めれば安心ではなく、
日照りが長いほど目減りする**。

## 稲作

稲は土壌水分ではなく、**田に張った水**で育つ。

* 水深 0.05〜1.0 のあいだで生育する。**季節には依らず、効くのは水位だけ**
* 涸れれば育ちかけの稲も枯れていく
* 深く浸かると生育は止まるが枯れはしない。水が引けば続きから育つ（稲の耐水性）
* 畑（麦）は土壌水分だけで育つので湛水が要らない。日照りの保険になる代わりに、
  大雨の冠水では育ちかけごと流される

平地に水を溜める手立ては初めからある。**堀割で掘り下げれば水が流れ込んで湛水する**。
畦は掘っていない周りの地面そのもの。

## 土を掘り、土を積む

地面を削るのは**堀割**、盛るのは**土手**。掘った土はそのまま蔵に入り、
**土手・堰・水門はその土で築く**（丸太は要らない）。

| 普請 | 費用 | すること |
| --- | --- | --- |
| 堀割 | 資材不要 | 地面を 1 段下げ、**土を 4 だけ産む** |
| 土手 | 土 4 | 地面を 1 段上げる（積み上げ可） |
| 堰 | 土 3 | 高さ 1 まで水をせき止める |
| 水門 | 土 3・板材 2 | 堰高を 0〜3 で加減する |

始めに持っている土は土手 3 マスぶんだけなので、**堤を伸ばすには掘るしかない**。
掘れば水が通り、その土で堤が立つ。撤去すれば積んだぶんの土は戻る（増えはしない）。
土の総量は地形の体積で頭打ちになるので、掘り尽くした谷にはもう土が出ない。
土は濡れても土のままなので、蔵が浸かっても傷まない。

## 荷捌きと舟運

共有の蔵は 1 つだが、**そこへ流れ込む速さに上限がある**。生産物はいったん建物の
荷置き場に積まれ、蔵へは「1 日に運べる量」しか流れない。荷置き場（24）が埋まると
建物は止まる。

| 経路 | 条件 | 1 日に運べる量 |
| --- | --- | --- |
| 村の中 | 蔵まで陸路 12 マス以内 | 60 |
| 大八車 | 〜30 マス | 8 |
| 人が背負う | それ以遠 | 2 |
| 舟運 | 集荷範囲 8 に船着場があり、蔵のそばの船着場と水路がつながっている | 100 |

**道**を敷いた列は 1 マスを 0.4 マスとして数えるので、道を通せば「村の中」が広がる。
舟が通れるのは水深 0.8 以上の列なので、堀割で運河を掘り、堰で水位を保つことが
そのまま物流網の整備になる。

## 火事

木と紙と藁でできた村なので、火が出れば町ごと持っていかれる。備えは三つ。

* **火の見櫓** … 番人がいれば周囲 14 マスの火事をその場で見つけられる。
  範囲の外は 150 tick 気づかれず、その間に燃え広がる
* **火消し詰所** … 見つかった火事へ何をおいても駆けつけて消す
* **防火用水** … 火元から 6 マスに水深 0.3 以上の水か天水桶があれば消火は 4 倍速い

延焼は火元と相手のあいだに水があると 1/20 に落ちる。**町の中を通した水路が
そのまま火除け地になり、消火の水にもなる**。土蔵は値は張るが燃え移らない。
樹木も燃えるので、山際の村は薪の手当ても考えることになる。

## 見た目

- 茅葺の寄棟（民家・杣小屋）、板葺きの切妻（蔵・木挽小屋）、いぶし銀の瓦（庄屋・精米所）、
  なまこ壁の土蔵。屋根の形と色で上から見ても何の建物か分かる
- 樹木は杉・松・竹の三種
- 季節ごとに空と光が変わる（平年は澄んだ青、大雨は鉛色、日照りは白茶けて眩しい）。
  大雨の季節はカメラの周りに雨脚が降る
- 水は深さで色が変わり、流れの向きにさざ波が流れ、落差で泡立つ。
  **人が歩ける・稲が育つ深さ（〜1.0）では水底が透けて見える**
- 燃えている建物と木の上に炎（明かりの影響を受けない色なので、暗い空でも位置が分かる）

## 地形

川は谷の底を流れ、その両側に**広い氾濫原**がある。氾濫原は水面より一段高いだけの
ほぼ平らな土地で、水辺から湿り気が届くので、開始直後から畑と村を広げられる。
そこから先は段丘が立ち上がり、高いところほど乾く（用水櫓が要る）。

## 水のしくみ

このゲームの中心は水のシミュレーションで、Timberborn と同じく「列（マス）ごとに
1 本の水柱を持つ」モデルを、**バーチャルパイプ法**（Mei et al. の浅水近似）で解いている。

```
bed  = 地面の高さ + 堰の高さ        … 水の底面
h    = bed + 水深                   … 水面
Q    = Q * 減衰 + dt * g * A * Δh / l * (1 - 通水抵抗)
A    = max(0, 上流側の水面 - 高い方の bed)   … パイプの濡れ断面
```

隣接する列の間の流量 Q を状態として保持するので、流れの慣性が残り、川は流れ続け、
水門を開ければ勢いよく放流され、貯水池は波打ってから水平に落ち着く。

* **A（濡れ断面）を式に挟むのが肝**。これは「堰を越える水の厚み」そのものなので、
  天端ぎりぎりではほとんど流れず、頭が付くほど勢いよく流れる。滝も同じ式で落ちる。
* **土手・堰・水門はすべて bed を上げるだけ**で表現される。越流も貯水も逆流防止も
  同じソルバから自然に出るので、構造物ごとの特別扱いが要らない。
  * 土手 … 地形そのものを 1 段上げる（積み上げ可）
  * 堰 … 堰高 1 で固定。超えた分だけ越流する
  * 水門 … 堰高を 0〜3 に変更できる。日照り前の水位管理の主役
  * 堀割 … 地形を 1 段下げて水路を通す
  * 橋 … ここだけは bed を触らない。歩ける面（桁）を水の上に足すだけなので、
    水は下を素通りする
* 各列から出る流量は保有水量を超えないよう一律に縮小するので、**負の水深は生じず、
  閉じた地形では総水量が厳密に保存される**（テストで確認している）。
* 1 tick（0.1 秒）を 4 サブステップに分けて解く。ゲーム速度を変えても dt は変えないので、
  10x でも水の挙動は同じ。

### 灌漑

水辺と稼働中の用水櫓を始点に、整数コストのダイクストラで湿り気の届く範囲を求める。
水平移動のコストは 1、1 段登るごとに +2 なので、高台は水辺のすぐ横でも乾いたままになる。
土壌水分は目標値へ徐々に動き、**乾くのは湿るより遅い**ので、日照りに入ってから用水櫓を
建てても間に合う余地がある。

## 構成

シミュレーションと描画は完全に分かれていて、`src/sim/` は Three.js に依存しない。
乱数はシード付きのものだけを使うため、**同じシードなら完全に同じ経過をたどり、
セーブして読み込んでも以降の進行が一致する**。
